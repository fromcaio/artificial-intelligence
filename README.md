# 🤖 Artificial Intelligence — Interactive Notebooks

This repository presents a comprehensive learning journey through **Artificial Intelligence (AI)** using **Jupyter Notebooks**, combining:

* Clear theoretical foundations
* Mathematical and algorithmic reasoning
* Visual and interactive demonstrations
* Real problem-solving applications
* Python implementations and experiments

The content is inspired by the **Artificial Intelligence** course taught by **Prof. Dr. Érica da Costa Reis Carvalho** at the **Federal University of São João del-Rei (UFSJ)**, covering topics from **knowledge representation** to **machine learning and natural language processing**.

---

## 🎯 Objectives

This project aims to be a **self-contained, university-level learning path** that guides students step by step through AI concepts and their practical implementation.

It provides:

1. **Interactive notebooks** that gradually build theoretical and practical knowledge
2. **Hands-on exercises** for reinforcement
3. **Implementation examples** for each major AI topic
4. **Clear modular structure** mirroring an academic course
5. A foundation for advanced AI subfields — from **heuristics** to **neural networks and NLP**

---

## 🚀 How to Start Learning

Start with the first module:

👉 `01-introduction/01-introduction.ipynb`

Then proceed in numeric order.
Each module contains:

* Core theoretical notebook(s)
* Algorithm demonstrations
* Exercises and small experiments
* Reflection and discussion prompts

### Recommended Flow

1. **Concept notebook** — understand the theory
2. **Implementation** — experiment with algorithms
3. **Exercises** — solidify your understanding
4. **Applications** — test ideas on real problems

## 🧰 Tools & Libraries

The notebooks use the standard AI and data-science Python stack:

* **Python 3**
* **NumPy** — numerical computing
* **Pandas** — data manipulation and preprocessing
* **Matplotlib / Seaborn** — visualization and analysis
* **scikit-learn** — machine learning algorithms
* **SciPy** — optimization & scientific functions
* **TensorFlow / PyTorch** — neural network implementation
* **NLTK / spaCy** — natural language processing
* **Jupyter Notebook** — interactive exploration

---

## 🧑‍🏫 Learning Style

All notebooks emphasize **clarity, intuition, and experimentation**, featuring:

* Progressive explanations (theory → algorithm → implementation)
* Detailed code comments and markdown notes
* Side-by-side visual comparisons and tables
* Exercises for conceptual understanding and coding practice
* Questions and reflection prompts

Where appropriate, visual elements include:

* Graphs of search algorithms
* Heuristic landscapes
* Learning curves and confusion matrices
* Reinforcement learning environments
* Neural network diagrams and attention maps
